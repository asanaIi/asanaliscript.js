## How connect asanaliscript.js to you JavaScript file?
**You can my framework to 2 methods**<br/>
#### 1 - Use require
```JavaScript
const asanaliscript = require('asanaliscript') // this search "asanaliscript" in npm
```
----
#### 2 - Use import
```JavaScript
import asanaliscript from 'asanaliscript' // is working if you have node_modules/asanaliscript
```
#### or this:
```JavaScript
import asanaliscript from 'https://cdn.jsdelivr.net/npm/asanaliscript@1.0.4' // without node_modules
```
